## What is a world model?

So what is a world model? In reinforcement learning, a world model is a model of how a world behaves. So for an agent, a very useful question is: what happens next if I act? If I push this cup, where might it move? If I take this turn, what might I see? That is a really important question in RL, where the modern use of the term in AI originated. It does not require the representation to be visual at all. The common idea is that we have an internal representation we can use to reason about something beyond the current observation. And we'll get more concrete.

[seg 74–81]

This is a classical and fairly general RL agent process for acting in a partially observable environment. The world has a state, but the agent receives observations that reveal only a part of it. The state estimator combines those observations with its previous belief and the action it just took. It produces an updated belief about what might be happening. The policy then uses that belief to choose an action. Now, don't get hung up on this specific implementation of an agent or a system. I use it only as an example to illustrate the use cases for a world model.

[seg 82–89]

So where is the world model here? It contributes implicitly to this process. Knowledge of how the world changes and how observations arise can support the state estimator, however that is implemented, and the same knowledge can support planning when we compute a policy. You can see how a world model supports many possible implementations of the agent as well as use cases beyond RL. It turns out it's really, really helpful to reason about the world and, in particular, to be able to make predictions about things that are not currently observed.

[seg 90–95]

But that still leaves so much flexibility in what a world model could actually do here. That suggests a functional taxonomy, and that's what my friends at World Labs wrote about this summer. We use that functional taxonomy to see what a specific world model does. For example, rendering produces observations: what would I see from here? Simulation produces a representation of a possible world state: what would happen if I pushed the cup? Planning produces actions: what should I do to pick it up?

[seg 96–105]

A world model can implement all of these functions or any subset, including none. The inverse is not true: only because a model supports one of these functions does not mean that it is a world model. It just helps us to categorize models better by what they do. And this is an extensible taxonomy of capabilities. These three operations connect directly to the agent–world loop, but they do not exhaust the questions we can ask or the computations we can perform using a world model.

[seg 106–111]

These operations are〔?〕 around the agent's representation of the world it acts in. Rendering tells us what we might observe. Simulation lets us explore consequences. Planning uses an objective to choose behavior. They can share the same underlying model, or be spread across multiple models — the world model, or world models, we use to implement this agentic loop.

Clearly, we need to separate the domain of what the world model is talking about. Between the spatial world, digital domains such as CRM or interfaces, and dedicated reasoning domains like models of the human cell, there are huge differences. We have additional axes that come to mind, like scale and resolution, and coverage. And I brought examples for these as well.

[seg 203–208]

So for example, if we look at scale and resolution: what spatial or temporal extent are we considering? A single room and a whole planet pose very different problems. This is a live model from livex.earth from this last Tuesday, and you can see Shanghai right in the center of it. It models satellites all the way down to weather for our planet. This has a very different scale than a local model for a city or room. It does fit our world model definition otherwise, and it can provide excellent predictive information for actions in that space.

[seg 209–214]

Coverage: which relevant parts and variables does the model maintain, including things that are not currently observed? That is the question behind this intersection example. So this is a video that I made with Kling 4.0, and we move around a generated intersection and keep encountering red traffic lights for all directions. What matters here is: would the model correctly reason about traffic lights from views other than the initial view? Does it keep simulating and updating them correctly? A locally consistent render for one frame may only be a part of what an application needs, or for another application it may be completely sufficient. And that's what this dimension covers.

## Where world models are headed

All right. So again, I'll continue discussing AI and reinforcement learning predictive world models. So looking forward, I want to extrapolate a little. To quote Ilya, let's feel the AGI together a little bit. So my thesis is that world models will define how intelligence interfaces with our world. World models define how an agent can explore a specific domain, navigate it, and interact with it. And the world model lets it ask useful questions and consider the consequences of operations.

[seg 239–247]

A world model is an interface between the abstract reasoning and the action and perception space. An agent can query a world model and obtain predictions. The world model, in turn, helps with observations and planning actions. Let's return to our illustrative agentic loop. This is the exemplary loop we know. Now, with more intelligence, we need more space〔?〕. And with the progress towards generalized agentic reasoning and multimodal models, they can take the role of a coherent long-term System 2 component.

[seg 248–253]

In case you're not familiar with the distinction between System 1 and System 2, it's a cognitive-psychology-inspired analogy: higher-level, slower reasoning in System 2; real-time perception and control in System 1; and sometimes extended to a controller in System 0. So the agent's long-term identity, goals, and reasoning happen in System 2. The lower loop now can become a System 1 module, and even domain-specific. It uses a world model to maintain an estimate of the situation and guide the actions in that domain. The connection between the two matters just as much. Reasoning needs to incorporate what the System 1 loop currently believes, including relevant uncertainty or a failed action, and it can then create or modify policies that work in real time.

[seg 254–260]

We can extend that to multiple domains and let the agent work across multiple interfaces at the same time. So these are two domain modules. One might handle physical interaction using vision, touch, and motion. Another might handle digital workflows using language and tools. A large multimodal model can reason across many different domains. So each module uses its own world models, possibly — again, this is just illustrative. Its current belief represents the domain state, estimation updates that belief, and a policy selects actions. The domain module contains those responsibilities; it is more than just the world model itself.

[seg 261–270]

So this is an example that can be extended. You can imagine modules for other domains, with representations and operations suited to each one. So when a task requires reasoning across domains or resolving a conflict, that is a natural responsibility for System 2 using higher-level reasoning. I'm leaving the detailed coordination mechanism open here. Also, consider the concrete implementation as an example. These boxes mainly describe responsibilities. So in a learned system, some of them may share parameters or live in the same network. So this is one proposed organization rather than a required architecture for intelligence. But it illustrates how much world models can enhance agentic workflows in powerful ways.

[seg 271–280]

World models are going to define how intelligence interfaces with the world. For some domains, we already understand the representations and operations quite well. There are many others where the most interesting work is still ahead. An example: what would a world model of a mind look like? What does someone believe or need? How can we communicate better and support each other with that understanding? Can that create deep alignment? Improving how people and AI will work and live together long-term is something I find deeply inspiring. So if you're interested in working on those questions too, let's talk. Thank you so much.
