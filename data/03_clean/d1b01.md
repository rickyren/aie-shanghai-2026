从最开始的话〔?〕，我觉得是整个 Personal Agent 的一个开始吧。今天要分享的，就是到当下，从各种虾，到各种办公的 Agent，再到现在像 Muse，还有 Grok Bot，整个目前的 Personal Agent，我觉得是非常的如火如荼，各种大厂、模型厂商、创业者，其实纷纷在入场。今天要讲的是我自己的一个实践，可能是在寻找另外一条路吧，就是谈谈用 YouMind 如何构建一种不一样的 Personal Agent，希望对每个人会有些帮助。[seg 1–6]

这个就是我关注到的，从 25 年 11 月，从虾开始，整个今年在 Personal Agent 这一块的一些关键时间节点。Tomo〔?〕和 Instinct，其实是今年 6 月份和 8 月份就已经有了，他们去连接邮箱、连接 Slack，做一些像记录〔?〕这一块，其实发展很快。还有一个点，是今年 6 月 23 号的 Claude Tag，不知道在座有没有人用过。它看起来是一个企业级的 Agent，但实际上它在人性上，它知道什么时候跟你聊天、什么时候不跟你聊天。目前 Claude Tag 是我自己用了将近两个月、体感最好的。它是 6 月份就有了。再往下，可能是最近大家在 9 月份到 11 月期间有接触的，像 Grok Bot、Muse，包括像俊元他们在做的 Today，还有一系列产品，包括 Manus 发布了 Cue，还有 dots。[seg 7–15]

相信在座的，投屏里面的这些 PA 有用过的，能举个手吧，大概看一下有多少人实际用过。OK，比我想象中要少，可能只有 1/5 的人用过。但大家应该都用过豆包吧？OK，用过豆包就算用过 Agent，所以也没啥。[seg 16–18]

我们往下，从去年年底到现在，真的是全面下场，非常非常多的 Personal Agent 都在做这些事情，这真的是非常有意思。我们去掰开看它工程的一些技术细节，会发现基本上大家都在做这几件事情。第一块是 Memory，就是在做记忆，包括基于你的各种资料、你的记忆，尝试去理解你，帮你去建 Profile。再往上，是通过各种连接器，把你的 Gmail 还有各种信息拿到，实际上是在感知你，相当于一个传感器，通过各种方式让 Agent 能够看见你看见的世界，能够读到你读过的资料。[seg 19–25]

再往上，这一届 PA 在主动性上会比 Coding Agent 更加主动，很多情况下会有 Schedule，你可以设各种定期任务，它会主动触达你。所以这块也是很好玩的。当然有一块是绕不开的，甚至目前真的做好的可能也不多，就是权限和隐私这一块。所以从工程技术上来看，整个 Personal Agent 可以说能力上是差不多的，从纯粹的工程上，我觉得大家都是在做这些事情吧。[seg 26–30]

核心区别是场景。回到场景，我觉得这边就比较有意思了，每个 Personal Agent 主打的场景可能都会有些不一样。像 Tomo AI，核心是让它把 Gmail 连接之后，你发现真的感觉 Tomo AI 做了一个比 Gmail 还好的邮件客户端，真的把你的邮件管得很好。像 Grok Bot 也是。总之大家如果有尝试过的，基本上目前的 Personal Agent 都在帮你处理很多生活杂事，帮你看邮件、做会议纪要、做简报或者写周报之类的，很多很多事情都在做。还有一些比较有趣的，比如关注你的身体健康，根据一些健康数据给你提醒，有非常多这样的场景。[seg 31–38]

上面这些场景看起来很多，我觉得很有意思的是，之前跟一个朋友聊天，我们说这么多场景里面，真的去细掰的话，会发现可能就两类场景。一类是把我们日常不想干的事情，通过 Agent 去帮我们干掉，这是在解决我们的烦恼。比如有些订阅，不知道有没有取消，通过 Agent 帮你去取消，这个场景真的是一个烦恼，一旦帮你解决之后是挺方便的；包括像一些订票、邮件，这是一块，帮你解决你不想干的事情，是解决烦恼。[seg 39–44]

第二块，也是目前在自媒体圈比较流行的：有了 Personal Agent 之后，终于可以开始做内容自动化工厂，让自己的各种碎片时间无缝利用起来，尝试去涨粉、涨流量，其实很多是满足内心里想被更多人关注的一个欲望，甚至通过这种获取流量的方式能够去挣钱。所以这是欲望满足。但无论是烦恼还是欲望，我觉得都是很正常的需求，能解决也都是很好的。[seg 45–51]

但是真的去想的话，又发现这两类其实更多是向外的。回到我们内心里，我们真的有这么多烦恼吗？真的有这么多欲望吗？是不是有个 Agent 能够帮你去解决一些不太一样的东西？[seg 52–56]

我们来看第一块，前面是 Muse 的 Alexandr Wang 的一句话：通过 Muse 让 AI 把一些让自己很烦的事情做掉，后续你就能够把时间花在想做的事情上。这是 Muse 的一个美好愿景。但实际上，我们无论看中国还是海外，会发现在目前这个时代，第一，日常杂事对于绝大部分人来说也没那么多，其实我们有很多时间，但我们真的会把这些时间花在想做的事情上吗？可能不一定是我们主观〔?〕的东西，更多是各种环境，使得我们真正的时间去刷短剧了、去刷短视频了，或者去看 TikTok 了。[seg 57–65]

哪怕有人把时间省下来，各种 Personal Agent 发挥到极致，真的能让我们把各种烦恼的事情解决掉、把欲望都满足掉之后，我们真的会去干我们想做的事情吗？这答案肯定是否定的。包括为什么很多人无论熬夜到几点——包括我自己有段时间，哪怕一看已经一两点了，很困了，就是有点睡不着，还会打开手机，去刷刷短剧，或者看看 X。为什么人明明困了，还会想在睡前花个半小时、一小时去刷各种媒体？从心理学上来讲，这很大程度上是补偿机制：因为白天很多事情是身不由己的，到了睡前你终于有了一些自主权，所以你想去刷。其实深夜刷手机是一种人的自由，是人在夺回自己的选择权。[seg 66–73]

但是你看，我们的 Personal Agent 能够帮我们夺回主动权吗？我感觉是做不到的。所以怎么说呢，Personal Agent 最重要的不是 Agent，是前面那个 Person，是人。人的主动性，在这一届 Personal Agent 里面有没有人去关注，让更多人更加关注自己的主动性？[seg 74–77]

所以回到这点，我觉得在座参加线下会议的，一定程度上都不是想着天天刷抖音的，而是在内心里，除了烦恼和欲望之外，还是想学会一些东西，比如学会更好地创业，来会场去交一些朋友；在内心里会有想做的事情，无论是 OPC 还是创业，想把自己的作品做出来，内心里一定是有自己想做的。但这跟小素描〔?〕，我觉得一定程度上是最本质的。其实我们每个人都有这个能力，除了烦恼和欲望之外，我们的本心其实都是非常之好的。我们更需要的，可能是一些东西、一些环境，来把我们本心的这个东西给点燃。[seg 78–85]

点燃的方式之一，我自己两三年的时间里觉得，就是创作。AI，在国内我们叫 AIGC，是生成式内容，这种生成能力让我们在座的每一个人在内容创作这一块，可能都有了一种更好的选择权。我们之前在门户时代、在报纸时代，是看别人编辑好、选择好的东西；到了搜索时代，内容极大丰富，我们可以通过谷歌去搜索；然后到了今日头条、到了抖音、到了红果，我们其实一直被推荐牵着走〔?〕。其实在消费侧，我们的被动消费、丧失选择权的消费，已经到了尽头。所以我个人会觉得，目前有个小趋势，或者说一个未来：在这个时代，我们更多的情况下，应该要从消费侧逐步走向创作侧。[seg 86–91]

整个 YouMind 要做的事情，就是基于上面这个想法。更多想做的可能不是 Personal Agent，而真正需要的，其实是创造一种环境，因为人是环境的反应器。无论是微信，还是 YouMind，还是任何一个产品，它都在营造一个环境。所以 YouMind 想做的，就是你和 AI、和你的很多 Agent 一起，更好地去创作。[seg 92–96]

而且这个创作更多是给自己看的。这边我分享一个数据：目前 YouMind 大概已经有上千名 Max 付费用户，就是一个月付 100 刀的，在 Max 用户群里面，每个月平均会做 15 个 PPT。我当时很好奇，以为 YouMind 在进军 PPT 界，在和 Gamma 和 Genspark〔?〕竞争。我说完蛋了，因为 Gamma 和 Genspark〔?〕资金雄厚度都会比我多，如果真的做 PPT 的话，可能没机会。但是我后来通过用户访谈发现，很有意思，很多人在 YouMind 做 PPT 是做给自己看的：一个月平均两天做一个 PPT，15 个里面只有一两个会给别人看。所以这个真的很有意思。[seg 97–104]

包括海外，谷歌有做 NotebookLM，它里面也有一个很好玩的现象：很多人在上面做播客、做视频概览、做 PPT、做信息图，其实都是给自己看的，并不是给别人看的。所以给自己看的需求，能够越级〔?〕，就是在 ToB、ToC 之外，还有 ToM，能够让自己有所不一样、有所成长，其实也是一个很大的市场。[seg 105–107]

整个 YouMind 从功能上，我觉得跟大家都差不多，就是 Memory、Skill 这些东西。所以从工程去解构的话，任何 Personal Agent 产品都大同小异。但最终还是回到场景。回到场景上，目前 YouMind 的核心答案是两个场景。第一个场景是 Create to Learn，就是通过学习的方式去创作，是费曼学习法：你得把东西通过自己的方式讲出来，或者做成 PPT，或者写成一篇文章。在这个过程中，你对一个主题、对自己的一个好奇，会让你学得更多。之前有个朋友开玩笑说，YouMind 其实是全球第一个费曼 Agent。这个确实没有人做过，而且我感觉也确实很贴切，如果大家听过费曼学习法、想实践的话，YouMind 应该是一个不错的工具。[seg 108–117]

这是第一块，Create to Learn。第二块我觉得也很重要，是 Create to Earn〔?〕。学习和创作、创作和学习，如果不能正循环也不行。在这种情况下，还可以 Create to Earn〔?〕，这个 Earn 当然包括去变现，通过各种方式去接商单、成为自媒体，这是一种 Earn。这个 Earn 我觉得也包括你去赢取别人的连接和信任。比如你之前从来没有发过小红书，你通过 YouMind 第一次做出了一些好看的图文，然后你去发小红书，有了第一个点赞、第十个点赞、第 100 个点赞，这种 Earn，你赢得的是一种连接感，当然其实也是内心的喜悦。我觉得通过 AI 工具去赢取你内心的喜悦和成长，也是一种非常重要的 Earn。[seg 118–126]

而且我们很多时候在这个时代，其实不存在怀才不遇，但是存在自己没有才华。我们每个人生下来，在某些点上或多或少都会有一些天赋点，但这些天赋点要变成才华，是需要经过刻意练习的。这种刻意练习，可能真的有时候要花个几万小时，不一定要到 10 万小时，但是几万小时是需要的〔?〕。这几万小时在 AI 时代，通过 AI 工具，刻意练习的过程可以急剧地加速，可以让你之前没有拍过影视、没有做过音乐，通过 AI 快速去加快这个进程。这是目前 YouMind 打的两个核心场景：一个是学习，一个是真的去变现也好、去发自媒体也好，去做内容的一些正反馈。[seg 127–135]

我举一个具体的案例。目前投屏的这个 Slides，其实就是我昨天晚上和今天上午在 YouMind 里面做的，大家看这个投屏是一个真实的截屏。我就是打开 YouMind，新建一个 Session、一个 Task，跟它说我要来 AIE 做分享，大概想讲什么，然后它就把整个 PPT 给跑出来了。有了这个初稿之后，你就可以不断地跟它交流，把这个 PPT 按照你的想法做出你想要的样子。整个 PPT 做完的过程，既是做 PPT，更多其实也是我自己思路的梳理，是一种学习和成长。[seg 136–142]

还挺有意思的是，每一轮下来之后，它都会更加懂我，因为记忆和偏好在每一轮交互里面，在 YouMind 里面都沉淀下来了。比如因为这个 PPT 改得比较多，它第一版的时候 PPT 里面有带页脚，因为目前这个是图片版〔?〕，修改起来很麻烦，所以我会告诉它，在这个 PPT 里面后续生成的页面不要带页脚，我只要说一次，它就能记住。更好玩的是，在这个 PPT 里面，关于 YouMind 的理解，它是把我过往一年多跟它的交互、所有的资料、记忆都记住了，它可能比我还懂 YouMind。但它懂的是 YouMind 的过去和当下，我知道的是 YouMind 的未来，所以我跟它会形成一种很好的互补关系：我会告诉它 YouMind 应该去往何方，它知道 YouMind 之前经历过什么，所以它就会和我一起把这个 Slides 给做出来。[seg 143–148]

这也是我们自己、也是 YouMind 很多客户非常常见的四个阶段。在 YouMind 做创作，写文章、做图片、做 PPT、做视频，基本上都会经历这四个阶段。第一个阶段跟用豆包一样，直接跟它说，说完之后这个 Agent 会给你一段一段的输出。这种情况下，我觉得所有 Agent 都差不多，它的核心差异来自于模型，跟产品本身关系不大，这是直接写的阶段。第二个阶段会稍微往前一步，你会带着你的一些私有化资料给它，你的一些文件、日记、平时的所思所想、平时的录音，都给到它之后，在第二个阶段它就已经可以帮你干活了，能写周报之类的。但这个还谈不上创作，是属于第二阶段。[seg 149–156]

第三阶段，你可以把你的一些东西，比如做某种类型的 PPT，做完之后让它沉淀为一个 Skill，这个 Skill 就会不断减少你日常的一些事情，然后往前做。最后，目前你甚至可以把 PPT 一键转成视频，实现一鱼多吃，在很多情况下可以尝试一些不一样的事情。[seg 157–163]

最后三页我想讲一下。目前看到的市面上的各种 Personal Agent，我觉得更多是跟你订票、邮件、找流量，反正干很多很多事情，但实际上都是在尝试减少你的烦恼，然后增加你的欲望。但这都是向外求的。回到向内求的话，我觉得是我们希望学会一种新的能力，希望把心中想做的某件事情做得更好。在这个层面上，如果有向内求的一些欲望，可以尝试下 YouMind。[seg 164–167]

还有一个，也是我跟少数朋友有提到过的：目前这个时代，很多时候做产品都要想到贪嗔痴，很多都是往让人放弃选择权的方式、让人更贪更嗔更痴的方式去走。但我觉得这个时代可能更有意思的事情是，借助模型、借助 Personal Agent，是有机会让每个用户更加有戒定慧的。戒就是取舍，你知道不做什么，这是非常非常重要的，比如深夜了，是不是不应该再刷手机了；定就是让你培养专注度，能够让你更专注，把事情完成；慧就是更加懂得怎么去选择。[seg 168–173]

最后一页，其实就是 YouMind 的一个定位吧。今天是 Personal Agent 的一个专场，但我觉得 Personal Agent 可能交给大厂们去玩吧。对于创业者来说，也许做一个跟环境相关的——人是环境的反应器，用户是环境的反应器——做一个更好的创作型的 Studio，可能会更有机会。OK，谢谢大家。[seg 174–177]
