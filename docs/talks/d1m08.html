在模型快速吞噬应用、信息差消失、内容泛滥的 AI 时代，线下社区与有质量的媒体成为创业者获得陪伴、种子用户、招聘与发声渠道的基础设施，但它们能否长久取决于商业模式（做交易而非广告）；创业者应回到解决真实需求，并有节奏、有干货地发声。

演讲骨架

  1. 三家社区/媒体各自介绍模式：WaytoAGI 从文档到线下实体 OPC 空间，十字路口以播客加 Hacker House 做陪伴与连接，42章经强调商业模式决定社区生死。
  2. 今年的变化：应用层创业者被基础模型挤压而往上（AI for science）或往下（infra、芯片、FDE）走，从业者与投资人普遍焦虑；社区里则有更多个人借 agent 开始真正商业化（OPC）。
  3. 社区如何与创业者合作：线下见面、实体空间、产品首发和找种子用户都发生在社区里；活动是工具箱，要有运营思路。
  4. 创业者如何发声：保持势能、分渠道释放，像做产品一样做 PR（灰度、调研），用视频化表达和干货，热点加深度。

讲者提出的框架

  • 社区/媒体的两条变现路径：所有媒体与社群最终只有交易和广告两条路：广告挂钩流量，交易挂钩社群，42章经选择放弃广告、走高客单高门槛的交易路线。
  • 往天上飞 vs 往地下钻：基础模型像冲来的坦克，应用创业者不能站在路中间，要么往上做 AI for science 等，要么往下做 FDE、交易数据、infra、芯片、推理加速、中转站。

非共识

  • 应用层创业者在模型公司面前被挤压，理性选择是离开中间地带，向上做 science 类或向下做基础设施类业务。
    所以我发现现在大家要么往天上去，要么往地下钻。
  • 当前创业叙事过度围绕模型解锁了什么能力，而不是用户需求；应回到第一性原理，解决真实问题。
    今天我们听得最多的是模型解锁了什么能力，大家说我讲个什么故事，是最新的模型带来的能力。
  • 产品团队用先做视频（PRV）取代 PRD 来预演发布，让同事和用户从使用者视角评判产品，再反向做产品；PR 也可像产品一样灰度。
    前两天看到张涛发了一篇文章，说自己的产品团队做事情先不叫 PRD，叫 PRV，V 是 video，就是我可以把一个想要发布的功能和产品先用 video 的形式 launch 出来，让很多人从真实用户的角度，或者把所有周边的同事变成用户的角度，来看你这场发布到底可不可以、你这个产品到底行不行，然后再反向去做。

信号

  • 市场格局 / 规律社区从线上群与线下聚会升级为实体园区，招募大量以 agent 为杠杆的一人公司（OPC）入驻，社区兼具孵化、订单分包和机会撮合的功能。
  • 市场格局 / 规律社区成为小团队产品首发和获取种子用户的渠道，例如短漫剧工具通过社区直播当天获得新增用户并产生收入。
  • 市场格局 / 规律创业者、投资人和二级市场普遍焦虑，投资人对 agent 类项目更谨慎，应用层创业者向底层基础设施和科研方向分流。
  • 关注的指标42章经观察到上播客的创业者最核心的诉求是招聘，其次是获得新输入与情感支持，而非单纯 PR；媒体与社群的价值取决于能否带来交易。

今年最大的变化

高宁：好的，相信大家对各位在做的事情都有了一个比较好的了解。我第一个问题肯定是关于今年的一些变化。今年我看到的大趋势是 agent 的产品层出不穷，让更多人拥抱了 AI。我觉得从 AJ 开始可以聊聊：回顾过去差不多 11 个月、一年左右的时间，你印象最深刻的一次活动，或者在一个创业者、一个社区参与者身上看到的最大变化是什么？然后再到 Koji 和曲凯。 seg 111–117

AJ：其实我觉得今年我们整个的感觉，就是从去年的"玩家"到了今年大家真正开始创业，能做一些实际上手的商业化的东西。因为 AI 的模型能力越来越可用，再加上现在的 AI agent、personal agent，它其实可以帮你解决最后一公里的事情。原来最早的 chat 聊天框，是它说一个什么东西，你自己去动手；现在能够让 AI 帮你完成最后一步。比如我最近最常用的一个 personal agent，它真的可以把我的那些订单、交易完成。 seg 118–122

所以我们在社区里边看到，我们这儿的 OPC 会比较多，因为我们把社区的伙伴分成了一个金字塔的结构。最下面的是一些小白入门，提升自己，在工作生活中能够更好地把 AI 用起来，成为公司里的优秀员工、AI 用得最好的那部分人。中间就是这些 OPC 的伙伴们，他们能够从公司里边跳出来，还能够赚到和原来在公司一样的钱，但是生活更自由，但这种对人的整体素质要求会更高。再上面一层，就是需要更好地去拿到一些融资，走到更高的商业创业变现。 seg 123–130

今年我们看到这样的可行性变得越来越高了。虽然我觉得投资界对于 AI，尤其像 AI agent 这样的投资好像变得越来越谨慎，因为人人都可以干了。但是因为我们社区的伙伴数量是很大的，AI 模型能力的提升给了大家更多的勇气，说好像我跟大家平均水平线差不多，我也可以出来干点啥。而且他们做的很多是非常细小、下沉的市场，在那里面他们能获取自己的经济利益报酬。这是我看到的，因为模型的可行性带来的整体水平的提升。这也是为什么北京、成都这些 OPC 的社区真正可以建立起来，有更多的 OPC 真的在运营自己的一摊事情或一个事业。 seg 131–139

高宁：所以需要一个空间，我觉得这也是今年才起来、你们才来做的事。 seg 140–140
