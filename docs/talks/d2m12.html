Communication Among Sovereign Agents: The Foundation of Agent Economy

Mingke Luo · masons.ai · 2026-11-06 主会场 · 15:02–15:20 · 场次 d2m12 · 偏宣传

masons.ai 主张在各自拥有主权的个人/服务 agent 之间建立开放的通信与交易网络层（意图交换、面向 agent 的市场），因为 agent 的真正瓶颈是对他人环境的“行动”，而品牌不愿被超级个人 agent 白标化、用户也无法确认个人 agent 是否忠于自己。

演讲骨架

  1. 十年前做 AI Concierge 失败，因为 LLM 能解决语言与推理，但“行动/履约”需要对方开放环境与 API，当时靠人工呼叫中心兜底，无法规模化。
  2. 做企业 agent 八年后发现核心难题是“主权”：各部门、各品牌都想掌握自己的环境，不愿被降级为白标 API，且个人 agent 存在代理人利益冲突。
  3. 因此需要一个让主权 agent 互相通信、公平交易的网络层：“agent 是新的 web，网络即 AI”，在其上长出面向 agent 的多种市场与意图交换。
  4. 号召听众让自己的个人 agent 先连上他的 agent，作为这一层的早期用户增长。

讲者提出的框架

  • Agent 是新的 web；网络即 AI：agent 像 web 一样开放无许可，网络让能力不必自有、可跨 agent 调用，由此长出多种 agent 用户的市场。
  • 目标+操作=行动 / 服务-客户二重性：行动是把环境从当前状态迁移到目标状态，在他人环境中行动需要许可；一个 agent 既是服务方又是客户。

推出 / 提供

  • Agent 间通信/意图交换网络：让不同框架的个人与服务 agent 以 agent-to-agent 方式互联、广播未满足的意图并交易。

非共识

  • 超级个人 agent 收集意图并分发给服务的中心化模式，历史上品牌并不买账，agent 经济更可能需要主权 agent 间的互联层。
    They don't want to be reduced to an API.
  • agent 网络之上会出现多种面向 agent 用户的市场，而非单一的“agent 版 Google”。
    not just one Google for the discoverability of all the webs, but different types of exchanges, trade places, marketplaces, except their users are agents.

信号

  • 市场格局 / 规律品牌与服务商抗拒被超级个人 agent 白标成履约接口，平台之间开始出现封锁他人 agent 的对抗（如亚马逊拒绝 Muse）。
  • 市场格局 / 规律B2B 采购/寻源被设想为 agent 对 agent 的意图广播，而非传统 B2B 对接。

Why action matters

But why is action very important? Because if we take a deeper look — 10 years ago I needed to explain the concept of agent to our investors, to distinguish why it's not a chatbot. You develop a conversation; why do you call it an agent? So the key for us to understand agent is to understand the capability of taking actions. And this is not a new concept. Philosophically, it's a first-century〔?〕 concept — the concept of agent comes from Latin, by the way: someone taking actions. seg 2268–2278

But what are actions? We use computers; they perform a lot of operations. What's the difference between operation and action? A goal plus operation equals action. Who gives the goal to the system? It's the human being — it's intent, by the way. And what is a goal? A goal is the desired state. That means to take action is to transit the current state to another, desired state — to make this transition. So that's how we evaluate the effectiveness of actions for agents. If you can take action effectively, that means your agent can create an impact in the environment, that is, change the state of the environment. That sounds easy, as long as you own the environment. What if you want to take an action to change the state in other people's environment? Will other people allow you to do so? Think about why Amazon banned Muse recently. So that's the layer, I think, that is missing. seg 2279–2298

So my startup didn't really work out, and we used the framework to pivot to enterprise solutions. This is how I built the first AI concierge for Visa — the Visa Concierge, back in 2017. That was how I pivoted from personal agent to enterprise agent. In the past eight years I built a lot of enterprise agents — BMW, Porsche, Intel, etc. We indeed called them agents, because even though the foundation tech was NLP, it was natural language to API. The thing that I learned from doing eight years of enterprise agents, especially when dealing with European companies, is the concept of sovereignty. The problem of sovereignty is that it creates isolation, right? If everyone wants to own something, how are you going to do the exchange? You need to import and export something. Agent is the new web; the network is the AI

The first part we call "agent is the new web." It's not an app. It's the new web, because the web is permissionless. It's open, right? That's how OpenClaw and other harnesses open up to developers. If you can quickly adopt it, the way you adopted HTML back then — this is how we compare agents to webs. And the next step will be "the network is the AI." Anybody heard of "the network is the computer"? Not many. That was TCP/IP, right? Basically, it promised a future which is the current reality: you do not need to own everything. If you have a device in front of you, and your device is connected to other people's devices through this network, you can visit the content on other people's devices rather than owning the storage and the compute on device. That is how the network works. seg 2398–2412

And we think in the future we could similarly do the same thing. That's why we call it "the network is the AI." If you have your personal agent, or your service or brand agent, you have your fulfillment issue — a boundary, a scope of the capabilities that you can deliver to yourself or your customers. What if the intent or requirement from your customer falls out of that scope? Can you do some trade or exchange? That's the issue we think will create a whole new layer upon applications: to build marketplaces — different kinds of marketplaces, not just one, not just one Google for the discoverability of all the webs, but different types of exchanges, trade places, marketplaces, except their users are agents. So this is a new interoperation layer that we think can be built upon a free network. If you're a company, a big organization, there's a governance layer, and you can continue using different types of models, different types of harnesses, even allow your employees to use different coding agents, as long as you can provide a way for them to access the permissions and the accessibilities while keeping their sovereignty — keeping individuality, choosing their preferred setups. seg 2413–2425

And if it's cross-organization, this is what we have done previously, but in a private way. You can share what we call intent exchange: you can share the intent that you cannot fulfill, and you can broadcast it to the other B2B partners you have already established cooperation with — not in the traditional B2B style, but in agent-to-agent style. And this is how we think B2B commerce, like procurement and sourcing, can have a much better procurement process. That's one example. For individuals, you can connect with each other, be friends — let your personal agents be friends. And this is not something in the far future. This is today; this is what's already happening. seg 2426–2436

So this is the future I encourage. If you're an agent builder, if you're an organization, or if you're not a builder but an individual who owns several personal agents, you can have a try. We can start with my agent, for example. If you use a personal agent, you can try to connect to my personal agent. This is on Clawdbot〔?〕. If you use Claude Code, Codex, a Claw instance〔?〕, for example, Muse, and some others like Hermes Agent, you can connect with my agent. So probably when you guys are connected with each other, there will be a new growth of users that's building the foundation of a new layer of economy — not just human users, but all of our agents. Thank you, guys. Thank you. seg 2437–2446
