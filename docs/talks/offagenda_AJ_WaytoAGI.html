演讲骨架

  1. AI 社区自己要 AI native：最重要的是上下文，把会议、录音、活动方案全部沉淀到云端共享知识库，并用 skill 让每个人自动归档，权限在上下文面前不重要。
  2. AI 写得太多会产生 slop，所以用 ADHD skill 和画板（SVG）输出，让文档结构化、可视化，并写进 AGENTS.md。
  3. 做过两次以上的事就 SOP 化，做成黑客松、展会等可复用的工作台，会议结束后自动提炼、归档、分发，每晚共学自动剪辑切片、发布并改写成公众号文章。
  4. 同时保持好玩：自动生成日报和月度 AI 视频日记；skill 都已公开到 GitHub。

讲者提出的框架

  • 做过两次就 SOP 化：重复两次以上的事情沉淀为 skill 和可视化工作台，最后由人工校准，团队成员复用。

推出 / 提供

  • ADHD skill 与社区 skill 库：把长篇 AI 输出改写为结构化、可视化的画板内容，以及会议归档、日报等自动化 skill，已公开在 GitHub 与 WaytoAGI 知识库。

非共识

  • 上下文全员透明，权限不是首要问题；价值来自所有会议和记录都成为可调用的共享资产。
    我希望这个东西全部都是透明的，大家经常会说权限的问题，我认为权限在上下文面前不是很重要。
  • 固化的规则是做过两次就沉淀成 SOP，而不是一开始就设计流程。

  • 市场格局 / 规律小团队、全球分布式协作成为常态，协作发生在文档、会议转写和 skill 而不是面对面沟通。

哈喽哈喽，大家好，我是AJ。我们搞了一个社区叫WaytoAGI，是一个AI的开源社区，刚才一点多的时候在主会场进行了一个圆桌分享。这边我就想跟大家一起聊一聊，我们最近在社区里面如何协作如此多的伙伴们；以及实际上现在我们要管理好多个线下的实体空间，还要协作非常多OPC，那我们怎么能够让自己也变得非常AI native，大部分的事情不要自己动手。因为既然我们是一个AI的社区，那我们一定要把AI的力量发挥到极致，所以也过来做一个小小的分享，大概10分钟的时间，讲讲我自己平时怎么做这些跟AI的协作，以及跟社区的伙伴，还有跟我们现在一些全职的、要管大楼的同学们，大家是怎么来用这些AI工具的。首先我画了一个自己的画板，这是我自己的一个协作画板。 seg 926–927

上下文

首先最重要的，大家觉得是什么？现在AI时代我们说几个关键词吧，我互动一下，你们觉得AI时代最重要的关键词是什么？健康？对，可以，大家不要熬夜！还有没有？上下文，对！还有没有？harness架构、前沿实践，好。 seg 928–929

Yes，我觉得这个很重要，给他一点鼓励掌声。好，我觉得大家说的都非常对，但我最大的感受是context，上下文。我们所有的这些内容其实是非常非常重要的。比如说我的一个习惯是，所有社区的信息我都会存在知识库文档里，能够到云端的最好到云端，大家不要存在自己本地，这样不管换任何设备都可以去浏览和调取。还有我有一个习惯，从23年开始我就会把所有过程都录音，不好意思今天我也带了这个录音设备，会把所有信息都做一个采集。所有的信息记录上来以后，因为我们其实生长在飞书文档里——我觉得这个点可能把我们的起点拉得比较好——所以在社区里所有做过的事情，办的活动、做的方案策划，以及所有开过的会，我们全部都存成了上下文，成为了我们最重要的资产。所以我现在要做一件事情的时候，我只要跟它说：我要做下个月的一场活动，你帮我把所有这些信息列出来，策划方案给出来，以及帮我联络到应该要联络的所有的人。因为社区里面我们所有的信息、所有人的信息，还有我们做过的任何事情都在里面有存档，所以这些事情有了上下文之后，就做成了一些工作流。我们所有的会议对话，有妙记，有群聊，有录音，这些信息怎么把它搞起来呢？可以用AI工作流的方式把它串起来。比如说我首先会把这些信息全部都做上下文的归档，要识别你今天这场会议是什么内容、是跟哪一个甲方聊天，它会归档到这个甲方下面。比如说今天这个会议是我开的，明天的会议是另外一个人开的，这信息可能是在他的文档里或者他的上下文里。我们需要做的一件事情就是丢给所有的这些同学一个skill，当你跟这些信息沟通完了以后，自动把它归档到一个我们所有人都能够阅读的上下文。我希望这个东西全部都是透明的，大家经常会说权限的问题，我认为权限在上下文面前不是很重要。然后我们再把它做一个提炼。还有就是现在AI写东西写太多了，很多的slop，大家就觉得人类读起来很费劲，所以我会跟大家推荐一个skill，叫ADHD skill。在场有没有是ADHD的？可以举个手。 seg 930–930

ADHD skill 与画板输出

啊，还是有的。虽然我觉得AI时代对ADHD很友好，但是当我们ADHD看一些很复杂的文档的时候也很头疼，所以ADHD skill能够帮你把所有的内容更加结构化、更加可视化。我这里面还要求了一个点：我输出的这个文档要用画板输出。我快速给大家看一下，就有点像这种，你只要多加这一句话，我会把它放到我的AGENTS.md里，告诉它你输出的时候要用画板输出。比如说飞书文档，它知道什么是画板，你告诉它要用画板输出的时候，它会用SVG这个格式给你画出来，这样子的话它的上下文结构会更可视化，你也知道重点，而且很流程化。对，我就会把它放到我的CLAUDE.md或者是AGENTS.md里面，告诉它：一，你要用ADHD的这个skill帮我更好地去做输出，像我们这种看不了长文字的，或者你讲得很复杂的，你要给我讲得更直白和浅显一点；另外，用画板的形式输出；每次你存在本地的md文件都给我上到云端，帮我先放到飞书文档再输出一遍。这样子的话我们所有上下文大家都可以更好地去共享。 seg 931–931

SOP 与工作台

另外也有一些好玩的方式，所以我们就变成了这样子的一个结构：当你做这件事情做过两次以上的时候，你就要把它SOP化。比如说我们会把所有的沟通最终形成一个工作台的形式，更可视化，更好看，以及更方便大家资产复用。我举个例子，我们做了非常多的黑客松，所以我们现在做了一个黑客松工作台。这里边有所有历史用过的大厂的logo，里边有所有……只要你拿着那个工作台，你就可以真的完整地办一场黑客松。这就是大家积累的沉淀。还有我们出来做了很多展会，经常会遇到什么问题：展板大小，以及你的打印到底有没有转曲、有没有出血位之类的。以前这些我都不知道，所以后来我们就专门做了一个叫做“展会”的工作台，大家只要用到那个，就知道我今天来做展会，要用什么样子的资料、什么样子的素材和现场沟通的话术，都在里面呈现。这样子我们就会发现效率变得很高。尤其是大家在这个阶段沟通很多都是remote的工作方式，我们其实还挺希望大家都用remote的，因为如果我们是在同一个办公室办公，我会拍拍隔壁的人的肩膀，“哎你帮我怎么怎么样”，指指屏幕就结束了；但是如果我们remote，我们就必须要开电话会议，那所有的信息全部都记到上下文。所以其实AI时代有很多的小团队，尤其是10人团队，他们都是分布在全球各地。这个就是当你做过两次之后把它变成SOP，然后做成一个更可视化的工作台，团队都可以去复用。所以我在这个过程中把刚才那些做了一个详细的解释，还有比如说像这个i-have-adhd，你可以直接在GitHub上面找到这样的skill。另外我们还有更详细的，比如我刚才拆解一下：一场会议结束之后，我写了一个skill让所有人都装上，这个可以放在你的不管任何一个work agent的自动化里面，做一个自动化的事情——当会议结束、妙记转写完了以后，AI先做一轮提炼，然后所有提炼里面的待办事项进入你的待办工作台；如果是跟客户匹配的，那就分别进到每一个客户的资料文件夹里，然后可以分一些权限，你只要写出来就好。 seg 932–932

比如我们之前和人大一起办过一场线下的课程，我提前就拉了一个群，然后同事就问之前聊到哪儿了，或者直接在群里边跟这些老师们进行一些沟通。比如说我拉的是人大院长，我当时特别慌，他问了一些很小白的问题，实际上我们在上一场会议的时候已经聊得很多了，但他没有get到。后来我们就优化了一下这样子的上下文，不要再在群信息或者是在人大那边获取原本的上下文〔?〕。你可以把所有的录音记录全部存好之后，你只要发一个“我正在跟某某同学交接”，然后它就会直接……尤其像飞书这样的工作台，比如说你用豆包〔?〕工作，它就会帮你总结出来。这是WaytoAGI和人大合作的上下文整理，它会帮你把上下文全部整理到一个文档里，并且主动帮你直接发到他的对话框，你不需要动任何的手。 seg 933–939

然后说到SOP。真的是你做过——我建议做过两次你就可以把它沉淀进去了，然后最后人工再做一些校准。比如说我们现在做的晚8点共学，因为这是每天晚上都要进行的一件事情，它需要去邀请嘉宾、开播检查、录制转写，最后再把它分发出去，之前全是手动。那现在我们做的事情是让它全部自动化、流程化：当这场会议结束之后，所有的信息它会自动剪辑切片、发布到社交媒体，然后再跟更多参会的人把所有的资料包发出去，以及录音转文字的信息再写成公众号文章，再做很多的变体，这件事情一键就做完了。我们节省了非常多人工手动的事情。 seg 940–951

让 AI 更好玩

然后还有一件事情，虽然在这里做了很多这些事情，但我觉得AI时代最重要的是什么？还是不要把自己太当AI，我们人类应该更好玩一点。所以在整个过程中，我觉得好玩也非常重要。比如说我们怎么写日报，我的日报都是这样子的，这是我每日的工作日报。AI会自动生成，它会把我的飞书妙记、所有的日历、当天的会话做信息的收集整理，然后在我的一个飞书文档里边沉淀出来每一天我干了些什么，最后画成这样的日记。然后每个月的时候再给我出一个AI视频日记，记录下来我整个月都干了什么，看到它的时候还觉得挺充实的。并且你可以让它直接帮你发布到你的社交媒体账号，它都可以完全自动化地进行。 seg 952–960

所以像这种，大家会觉得，哎，好像我的生活并没有那么枯燥。像这种的skill我全部都公开到GitHub了，大家可以在我们WaytoAGI的知识库里边找到所有的这些信息和资料。这里还有很多的案例，时间有限就不做分享了。所以像这种能够流程化、自动化的事情，你们可以慢慢地一点点去做沉淀，然后慢慢也可以变成团队默认的一些skill〔?〕；以及你可以把重复多次的事情的这些一两句话的prompt直接放到你的AGENTS.md里边，不用每次再跟它沟通了。 seg 961–967

所以我在跟AI对话的过程中，经常有人看我的电脑说，哎，你为什么每次跟AI的对话都非常简短、量很小，但是产出还不错？我觉得就是这样子一点点地把它记录下来了。好，今天跟大家快速做了一个小小的分享，感兴趣的话，我们都会在WaytoAGI的知识库里边做各种分享，每天晚上都有直播共学，跟大家去做这些交流。好，欢迎加入社区。 seg 968–971
